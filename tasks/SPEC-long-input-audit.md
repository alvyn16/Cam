# Long transcription, diagnostics and cache lifetime

Implemented and verified on 2026-10-18. The requirements below describe the original long-input gaps, now covered by bounded transcription/diagnostics, writable application caches and focused plus live acceptance. Exact test counts, release identity and measurement caveats are in IMPLEMENTATION_STATUS.md.

- Audio diagnostics: discover tracks through metadata without decoding each track twice. Analyze fixed-size blocks with exact whole-track RMS and the existing 50 ms tone detection semantics, including a final partial block. Reject invalid diagnostic frequencies/durations. Keep the existing short reference analyzer for regression comparison.
- Transcription: stream/decode microphone audio into bounded 16 kHz mono chunks, split near quiet boundaries, reuse one loaded Whisper context/state, and offset every returned word into the original recording timeline. Do not hold a full stereo or mono recording. Preserve exact existing transcripts on cancellation/failure and publish only a complete result. Closing/replacing the editor must cancel transcription/download/decoder work and join it. Progress should represent the whole recording. Test multiple chunk boundaries, silence, final partial input, errors and cancellation, then use real speech and a long fixture.
- Caches: opening, previewing and exporting a read-only package must work using writable application cache/scratch. Keep source media unchanged. Bound or evict unused owned cache assets without deleting imported media or assets still in use. Document disk requirements and errors. Test read-only sources, concurrent preparation and ownership/collision handling.

Whisper model memory itself is fixed by the selected model; transcript/event metadata grows with content. These bounds concern audio samples and scratch/cache lifetime. GPU source decoding/capture and direct USB input remain distinct parity capabilities.

Acceptance: the hour-long speech fixture retained all 42 expected words at three separated positions, with a 10.60 MiB main-process peak difference versus the short control. Hour-long audio diagnostics used 3.14 MiB peak private memory. The final optimized build previewed/exported an ACL-write-denied actual recording with every source hash unchanged. Shared CAMLOCK1 sidecar leases exclude GC while allowing atomic data replacement; ownership checks preserve foreign files. Active assets may exceed the 2 GiB cache target. Final tests cover concurrent publication/repair/eviction, decoder and native inference cancellation, atomic transcript preservation and actual console cancellation.
