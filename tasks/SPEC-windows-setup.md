# Easier Windows installation

Provide a downloadable setup executable for the existing tested Cam v0.1.0 binary, without rebuilding or changing recording behavior. Setup installs per-user to LocalAppData/Programs/Cam, downloads pinned FFmpeg essentials directly from its distributor over HTTPS, verifies SHA-256 before extraction/execution, and puts ffmpeg.exe and ffprobe.exe beside Cam. It creates desktop/Start menu shortcuts and a per-user Installed apps entry. No administrator rights, package manager or PATH edits are required.

First installation requires internet. A setup ZIP is an alternative to the self-extracting EXE; it is not an offline portable bundle. Keep the existing bare executable for users managing their own media runtime. The setup assets do not redistribute FFmpeg binaries. Retain downloaded runtime notices locally and record runtime provenance in the installation marker.

Use built-in IExpress and Windows PowerShell 5.1. Show a small progress window, allow cancellation during download, preserve an existing managed installation on a failed or corrupt download, reject unrelated destination folders, and preserve additional user files on upgrades. Refuse upgrades/uninstall while that installed Cam is running. Uninstall only managed application files, leaving recordings/settings and added user files intact.

Include the Visual Studio release x64 CRT DLLs app-locally; validate the extracted package hashes and confirm the actual GUI loads its three direct C++ runtime imports from its installation directory. Do not depend on a developer machine's globally installed C++ runtime. The launcher explicitly addresses its local batch file and uses inbox Windows PowerShell modules, including when inherited PowerShell 7 module paths or hardened current-directory lookup settings are present.
