# screenstudio-rs (working name: glide-rs)

A fully open-source, fast, native Rust macOS screen recorder for polished product videos.

Behaviour was reverse engineered from Screen Studio using REA and Claude Code. This project is not affiliated with or endorsed by Screen Studio or its authors, and contains none of its original code or assets. Capture pipeline builds on rec-rs by Michael Shimeles.
