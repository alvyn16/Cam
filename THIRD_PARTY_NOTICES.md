- windows-capture 2.0.1: MIT, https://github.com/NiiightmareXD/windows-capture. Supplies the Windows Graphics Capture integration. Uses Windows graphics APIs and does not change Cam's project format.
- nnnoiseless 0.5.2: BSD-3-Clause, https://github.com/jneem/nnnoiseless. Supplies RNNoise-based neural denoising and its built-in model. The crate retains its upstream copyright/license notices in Cargo's dependency source and distributed dependency licensing must preserve them.
- FFmpeg and ffprobe are external executables: https://ffmpeg.org/legal.html. They are not bundled by these build scripts. Their license depends on the build's enabled components; anyone distributing them with Cam must include the corresponding notices and satisfy that build's license/source obligations.

Windows Setup downloads the pinned Gyan FFmpeg essentials distribution directly from https://www.gyan.dev/ffmpeg/builds/ to the user's computer. It verifies the archive SHA-256 before running either executable. The setup assets contain Cam and setup scripts, not FFmpeg binaries. Setup retains the distributor's GPL license and README in the installed `licenses` directory. The exact version, download URL, checksum and provider website are in `packaging/runtime.json` and the installed `cam-install.json`. Cam invokes these separate tools as processes. FFmpeg source and build information are linked by the distributor; FFmpeg is not owned by Cam.

Windows Setup also includes Microsoft Visual C++ release runtime DLLs from the licensed Visual Studio x64 redistributable directory, deployed locally beside Cam. These files remain Microsoft software under their applicable redistribution terms, not Cam's MIT/Apache licenses. Redistribution details: https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files . The package and installed manifests list their filenames and SHA-256 checksums. Packaging requires an installed Visual Studio C++ redistributable directory or an explicit `-VCRuntimeDir` pointing to one; debug/non-redistributable DLLs must not be supplied.
